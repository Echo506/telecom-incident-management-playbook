# NOC Tier 2 Technician – Training Course

This course is designed for Level 2 technicians in a Network Operations Center (NOC) who handle telecommunications, VoIP, and enterprise network incidents.

---

## Course Structure

The course is organized into **13 thematic modules**, each containing:

- ✅ Learning objective
- 📚 Foundational knowledge you need
- 🎯 Key teaching points
- 🛠️ Suggested hands-on exercises

## Prerequisites

- Basic networking knowledge (OSI model, TCP/IP).
- Familiarity with Windows and Linux command line.
- Basic experience in customer service or technical support.

## How to Use This Course

1. Follow the modules in order (1 → 13).
2. Complete the hands-on exercises for each topic.
3. Track your progress in the [progress tracking sheet](progress-tracking.md).
4. Upon completion, you'll be prepared for NOC Tier 2 roles and certifications like CompTIA Network+.
