# Learning Path: From NOC Analyst to Incident Management Professional

## Phase 1 – Foundations (Weeks 1–4)

- Learn ITIL 4 fundamentals: incident, problem, change, SLA, OLA.
- Study NIST SP 800-61 incident response lifecycle.
- Practice mapping real tickets to lifecycle stages.
- Create your first runbook and communication template.

## Phase 2 – Operational Excellence (Weeks 5–8)

- Deepen network troubleshooting skills (routing, switching, firewalls, access circuits).
- Build additional runbooks for common incident types.
- Define a severity and priority model aligned with your environment.
- Draft an incident management policy.

## Phase 3 – Security and Governance (Weeks 9–12)

- Study ISO/IEC 27035 and basic SOC concepts.
- Add a security incident addendum to your playbook.
- Create a post-incident review template and run a mock PIR.
- Document metrics and KPIs for incident management.

## Phase 4 – Portfolio and Career (Weeks 13–16)

- Anonymize 2–3 real incidents as case studies.
- Publish this repository and reference it in your résumé and LinkedIn.
- Prepare interview stories using the “How to Use This Repository in Interviews” section.
- Identify target roles (NOC, SOC, ITSM, GRC) and tailor your narrative.
