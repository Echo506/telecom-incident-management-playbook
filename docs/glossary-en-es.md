# Bilingual Glossary (English – Spanish)

| English | Spanish | Notes |
|---|---|---|
| Incident | Incidente | Unplanned interruption or reduction in service quality |
| Outage | Caída / Interrupción | Complete loss of service |
| Circuit | Circuito | Physical or logical path providing connectivity |
| Demarc (Demarcation Point) | Punto de demarcación | Boundary between customer and carrier responsibility |
| NOC (Network Operations Center) | Centro de Operaciones de Red (NOC) | Team monitoring and managing network services |
| SLA (Service Level Agreement) | Acuerdo de Nivel de Servicio (ANS/SLA) | Contractual performance targets |
| OLA (Operational Level Agreement) | Acuerdo de Nivel Operativo (OLA) | Internal support targets |
| Runbook | Manual de procedimientos / Runbook | Documented step-by-step operational procedure |
| Escalation | Escalamiento | Transferring or elevating an incident to a higher level |
| Post-Incident Review | Revisión post-incidente | Structured lessons-learned session |
| Major Incident | Incidente mayor | High-impact incident requiring special handling |
| Ticket / Case | Ticket / Caso | Record of an incident or request in the ITSM tool |
| Carrier | Proveedor de servicio / Carrier | ISP or telecommunications provider |
| Vendor | Proveedor / Vendor | Supplier of equipment or services |
| Root Cause | Causa raíz | Underlying reason for an incident |
